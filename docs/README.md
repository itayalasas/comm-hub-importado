# Documentación de SendCraft

- `guias/`: cómo usar la API (API keys, plantillas, JSON anidado, flujos de PDF y facturas, API para partners).
- `infra/`: configuración de servicios (configuración dinámica, Gotenberg, PDFShift, webhook de Resend, APIs dedicadas).
- Las migraciones de base de datos están en `infra/neon/migrations/`.
